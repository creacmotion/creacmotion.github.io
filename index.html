유튜브 재생목록 예약 (YouTube Playlist Scheduler)

본인이 소유·관리하는 유튜브 채널의 재생목록에, 지정한 시각에 영상을 추가하고 맨 위로 정렬하는 개인용 Windows 프로그램입니다. 일반에 배포하지 않습니다.

A personal-use Windows tool that adds a video to the top of a playlist on the owner's own YouTube channel at a scheduled time. It is not distributed to the public.

개인정보처리방침 (Privacy Policy)

사용하는 데이터: YouTube Data API를 통해 인증된 채널의 이름·ID, 재생목록 목록, 재생목록 항목, 영상 제목에만 접근합니다. 재생목록에 영상을 추가하거나 순서를 바꾸는 용도로만 사용합니다.

저장 위치: 인증 토큰과 예약 목록은 사용자 본인의 PC에만 저장되며, 개발자를 포함한 어떤 외부 서버로도 전송되지 않습니다.

제3자 제공: 어떤 데이터도 제3자에게 판매·공유·제공하지 않습니다.

권한 해제: 언제든지 Google 계정 > 타사 앱 및 서비스에서 이 앱의 접근 권한을 해제할 수 있으며, PC의 프로그램 폴더 안 data 폴더를 삭제하면 저장된 정보가 모두 지워집니다.

Google API 정책 준수: 이 앱이 Google API로부터 받은 정보의 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다. 또한 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

English summary: The app only accesses channel name/ID, playlists, playlist items and video titles of the authorized channel, solely to add or reorder playlist items. Tokens and schedules are stored only on the user's own PC and are never sent to any server or shared with third parties. Access can be revoked at any time at myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
